# Исследование крупных и компактных галактик: наличие центральной SMBH

Дата: 2026-07-24

## Проверяемая гипотеза

Рост центральной плотности/компактности переводит центральную область через нижний порог квенча L1 или L0. После порога возникает устойчивый нижнеуровневый стационар, наблюдаемым проявлением которого может быть SMBH. Уровень трактуется как нижний порог допуска дефекта, а не верхний предел плотности.

## Данные

1. AMUSE-Virgo: 100 ранних галактик, Chandra; 32 ядерных X-ray источника. VizieR J/ApJ/714/25.
2. Структурные параметры ACSVCS: 98 совпавших галактик, эффективный радиус, средняя поверхностная яркость, индекс Серсика. VizieR J/ApJS/164/334/struct.
3. Прямые измерения масс чёрных дыр и параметров хозяев: 245 объектов, 240 пригодны для текущего анализа. VizieR J/ApJ/831/134/table2.
4. Независимая проверка occupation fraction: Zou et al. 2025, 1606 галактик в пределах 50 Mpc; для M*=10^11–10^12 Msun нижняя 2σ-граница f_occ >93%.

## Метрики

Компактность использована как эмпирический индекс

    C = log10(M*) - 2 log10(Re/kpc).

Это прокси локальной концентрации вещества, а не Θ-плотность и не энергетический функционал дефекта.

Ядерная X-ray активность является только нижней границей наличия SMBH: неактивная SMBH может не обнаруживаться в X-ray.

## Результаты AMUSE-Virgo

- Всего: 100 галактик; структурные параметры: 98; ядерные источники: 32.
- M* < 10^9 Msun: 1/10 = 10.0%.
- 10^9 <= M* < 10^10 Msun: 3/44 = 6.8%.
- M* >= 10^10 Msun: 28/46 = 60.9%; Wilson 95%: 46.5–73.6%.
- M* >= 10^10.5 Msun: 16/23 = 69.6%; Wilson 95%: 49.1–84.4%.
- Верхний квартиль компактности: 20/25 = 80.0%; Wilson 95%: 60.9–91.1%.
- Массивные и одновременно верхний квартиль компактности: 18/22 = 81.8%; Wilson 95%: 61.5–92.7%.
- Наиболее яркий по средней z-поверхностной яркости квартиль: 19/25 = 76.0%.

По квинтилям компактности доли ядерных источников:

    5.0%, 5.3%, 30.0%, 31.6%, 85.0%.

Исследовательский одношаговый разрез C=10.186 даёт:

- ниже: 12/76 = 15.8%;
- выше: 19/22 = 86.4%.

Разрез выбран по данным и не является заранее заданной физической константой.

## Модели AMUSE

Логистическая модель активности:

- только масса: AIC 99.43;
- только компактность: AIC 88.85;
- масса + компактность: AIC 74.98.

В совместной модели оба признака значимы:

- масса: p=3.61e-4;
- компактность: p=1.07e-4.

При использовании прямой средней поверхностной яркости и индекса Серсика:

- яркость: p=6.42e-5;
- масса: p=0.249;
- индекс Серсика: p=0.0615.

Следовательно, внутри этой выборки локальная структура центра объясняет вероятность ядерного источника лучше одной общей массы.

Квадратичная поправка по компактности не улучшает линейную логистическую модель: AIC 89.05 против 88.85; коэффициент квадрата положительный, p=0.099. Признаков верхнего спада в исследованном диапазоне нет.

## Прямые массы SMBH

Для 240 галактик с измеренной массой SMBH:

- rho(M_BH, L_K) = 0.676;
- rho(M_BH, компактность) = 0.274;
- rho(M_BH, центральная дисперсия скоростей) = 0.874;
- rho(M_BH, концентрация C28) = 0.493.

Компактность существенно добавляет информацию к общей светимости хозяина (p=1.42e-11), но не добавляет её после центральной дисперсии скоростей (p=0.563). Значит порог нельзя сводить к одной скалярной плотности: нужен локальный многопараметрический паспорт центра.

## Независимая проверка occupation fraction

Zou et al. (2025) анализируют 1606 локальных галактик с Chandra и моделируют наличие MBH независимо от текущей активности. Для галактик M*=10^11–10^12 Msun получена нижняя граница f_occ >93% при 2σ. Это непосредственно подтверждает формулировку «в крупных галактиках SMBH почти наверняка присутствует».

## Θ-интерпретация

Данные согласуются с цепочкой:

    рост центральной концентрации
    -> пересечение нижнего порога локального режима
    -> стабилизация нижнеуровневого стационара
    -> SMBH-подобное наблюдаемое проявление.

Лучше всего поддерживается не условие rho > const само по себе, а функционал

    K_n[rho_c, compactness, brightness, central modes, connectivity, Q, kappa] >= 0.

Наблюдаемая зависимость имеет форму нижнего перехода с дальнейшим ростом/насыщением. Верхний предел уровня данными не обнаружен.

## Ограничения

1. AMUSE-Virgo содержит ранние типы одного скопления; это не универсальная выборка всех морфологий.
2. X-ray активность ниже истинной occupation fraction.
3. Компактность C — прокси, а не восстановленная Θ-плотность.
4. Положение перехода C=10.186 является исследовательским и требует независимой выборки.
5. SPARC сам по себе имеет слабое пересечение с каталогами прямых масс SMBH и не должен использовать не-совпадения как доказательство отсутствия SMBH.

## Итог

Гипотеза подтверждается в сильной, но уточнённой форме:

- для крупных локальных галактик occupation fraction действительно близка к единице;
- высокая центральная компактность резко повышает вероятность обнаружения центрального SMBH-источника;
- данные поддерживают нижний порог возникновения режима и не показывают верхней границы;
- плотность является важной частью критерия, но не единственным параметром квенча.
